Under the hood

How it's built

A real-time application, not a set of renders.

  1. 01Unreal Engine 5, C++.

    The whole app — camera, interface, data — is written in C++, and the interface adapts to the screen it runs on.

  2. 02One continuous camera.

    From the city map to the yard, into an apartment and down to a walk: every transition is one camera move, never a cut.

  3. 03Data in, showroom out.

    Buildings, apartments, prices and statuses are imported from the project's model and tables, so a new project is rebuilt, not redrawn.

  4. 04Baked analysis.

    Walking times around the plot and sunlight in every apartment are computed offline from the model.

  5. 05The web from the same scene.

    The 3D on this page is captured from the same Unreal scene as Gaussian splats and point clouds and runs in the browser.
